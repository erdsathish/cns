## GitHub Pages

1. Replace the existing `index.html` with the new `index.html`.
2. Replace the existing `style.css` with the new `style.css`.
3. Keep `README.md` in the repository.
4. In GitHub, open **Settings → Pages** and make sure GitHub Pages is enabled from the `main` branch and `/ (root)`.
