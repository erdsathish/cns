# Click N Scans — Linktree-style landing page

A static, mobile-first landing page that can be hosted directly with GitHub Pages.

## Files

- `index.html` — page structure
- `style.css` — responsive design and brand colors
- `assets/` — place your real logo here

## Before publishing

Open `index.html` and replace:

- `YOUR_PHONE` with the phone number for the Call button
- `YOUR_WHATSAPP_NUMBER` with WhatsApp number in international digits only
- `href="#"` for Instagram, Facebook, YouTube and the How It Works video with your real URLs
- Optional: replace the CSS logo with your actual `assets/logo.png`

## GitHub Pages

1. Create a GitHub repository, e.g. `clicknscans-linktree`.
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.

You can later connect a custom domain if needed.
